# Tool
If you have proficiency with a tool, add your Proficiency Bonus to any ability check you make that uses the tool. If you have proficiency in a skill that's used with that check, you have [[Fore Lindrov/2. Mechanics/Core/Advantage\|Advantage]] on the check too.
