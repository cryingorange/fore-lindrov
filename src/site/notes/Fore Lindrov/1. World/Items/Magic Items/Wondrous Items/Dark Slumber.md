## Description
A pendant with an obsidian centre that pulses with a shadow that swirls within the gemstone.

## Effect
**Store Object.** A creature holding this pendant can take the [[Fore Lindrov/2. Mechanics/Actions/Magic\|Magic]] Action to touch one object that isn't being worn or carried to store it inside the crystal.

**Dimensions.** The object can be up to 500 lbs, not exceeding a volume of 64 cubic feet. The pendant can only store one object at a time.

**Existing Storage.** If the pendant already has an object stored inside it, a creature holding the pendant can take the [[Fore Lindrov/2. Mechanics/Actions/Magic\|Magic]] Action to cause the stored object to appear in an unoccupied space within 5 feet of the  creature.
