# Description
This red gemstone glints with an unnatural light, almost as if it holds the power of the sun.

# Effect
A creature can take a [[Fore Lindrov/2. Mechanics/Core/Free Object Interaction\|Free Object Interaction]] to hold the gemstone up to their eye to see through it, doing so allows that creature to see through Magical [[Fore Lindrov/2. Mechanics/References/Light/Darkness\|Darkness]] (such as those created by the [[Fore Lindrov/2. Mechanics/Spells/Official/2nd Level/Darkness\|Darkness]] spell).
