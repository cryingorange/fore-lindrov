# General

Characters who don't have the key to a locked object can try to pick the lock using [[Fore Lindrov/1. World/Items/Mundane Items/Tools/Thieves' Tools\|Thieves' Tools]]. The [[Fore Lindrov/2. Mechanics/Actions/Picking A Lock#Lock Complexity Table\|Lock Complexity Table]] tells you how long it takes to try to pick a lock based on its complexity. 

At the end of that time, the character picks the lock by making a successful DEX (Sleight of Hand) check using [[Fore Lindrov/1. World/Items/Mundane Items/Tools/Thieves' Tools\|Thieves' Tools]]. The DC is determined by the lock's quality, as shown in the [[Fore Lindrov/2. Mechanics/Actions/Picking A Lock#Lock Quality Table\|Lock Quality Table]].
