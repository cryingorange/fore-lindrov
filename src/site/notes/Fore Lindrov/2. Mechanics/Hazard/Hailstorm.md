# Overview
Hailstorms bombard travelers with falling ice. 
Hailstorms typically last 4d4 minutes.

# Effects
On Initiative Count 20, each creature in a Hailstorm takes 1d4 Bludgeoning damage, a creature with Heavy Armour takes none of this damage.

# Travel
If you spend 10 minutes travelling through a Hailstorm without protection, you automatically gain one [[Fore Lindrov/2. Mechanics/Condition/Exhaustion\|Exhaustion]] level.
