# Object Immunities & Saving Throws
- **Damage.** An object is typically [[Fore Lindrov/2. Mechanics/Core/Immunity\|Immune]] to Poison and Psychic damage.
- **Conditions.** An object is [[Fore Lindrov/2. Mechanics/Core/Immunity\|Immune]] to all conditions.
- **Automatically Fails Saving Throws.** If an object is subject to a saving throw, it automatically fails unless otherwise stated.

# Object Damage Threshold Table

|**Material**|**Damage Threshold**|**Description & Examples**|
|---|---|---|
|Paper, Cloth, Rope|0|**Fragile.** Offers no resistance to damage. (e.g., Paintings, Curtains, Books)|
|Glass, Ice, Crystal| 0 |**Brittle.** Easily shattered. (e.g., Windows, Vials, Mirrors)|
|Wood (Thin/Small)|0 – 5|**Weak.** Standard furniture or simple barriers. (e.g., Chairs, Interior Doors, Chests)|
|Wood (Thick/Structure)|10 – 15|**Resilient.** Requires heavy force to crack. (e.g., Ship Hulls, Exterior Doors, Reinforced Crates)|
|Stone (Weathered/Hewn)|10 – 15|**Tough.** Hard to damage with standard weapons. (e.g., Statues, Old Ruins, Cavern Pillars)|
|Stone (Worked/Masonry)|15 – 20|**Fortified.** Engineered to resist siege. (e.g., Castle Walls, Keep Gates, Stone Golems)|
|Iron / Steel|20 – 25|**Hard.** Metal barriers. (e.g., Portcullis, Vault Doors, Anvils, Chains)|
|Mithral / Magical|30+|**Supernatural.** Enchanted or masterwork durability. (e.g., Magic Barriers, Dwarven Plating)|
|Adamantine|30+|**Indestructible-adjacent.** Immune to almost all non-siege damage. (e.g., Artifacts, Deity Structures)|
